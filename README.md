# 🛒 Amazon Affiliate Deals Website

This project is a demo-level Amazon Affiliate marketing site built with [ASP.NET Razor Pages] and [Bootstrap 5]. It’s designed to showcase daily and categorized Amazon deals using mock data, simulating the functionality needed for future API integration once Amazon Associates API access is granted.

## Features

- **Home Page**
  - Hero carousel with featured images
  - Daily deals section displaying product cards

- **Gaming Deals Page**
  - Displays gaming-specific affiliate products
  - Includes search and filter interface
  - Promo code copy functionality with toast notifications

- **All Products Page**
  - Displays all available affiliate products
  - Sortable by category
  - Featured deals carousel

- **Reusable Layout**
  - Shared `_Layout.cshtml` for consistent UI
  - Bootstrap 5 responsive components
  - Scoped CSS for cleaner design

## Tech Stack

| Category        | Tech Used                         |
